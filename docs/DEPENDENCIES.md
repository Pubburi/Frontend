# 이전한 의존성의 후속 점검

2026-10-31에 기존 lockfile을 유지한 상태로 npm audit를 확인했다.
보고된 경고는 14건(높음 8, 보통 6)이며 실제 이용 경로와 영향은 추가 검토가 필요하다.
검사 시점의 의존성 그래프 경고 수이며 실제 공격 가능성을 검증한 결과는 아니다.

- 직접 의존성 경고: Vue, Vite, Vitest, sharp.
- 일부는 현재 허용 범위의 업데이트로 해결 가능하고 sharp는 보고된 수정 버전 적용 시 호환성 확인이 필요하다.
- 기본 세팅에서는 원본의 의존성 버전을 유지했다. 별도 PR에서 패치 가능한 항목부터 적용하고 테스트·빌드를 다시 확인한다.
- React 전환 과정에서도 전환 전 Vue와 전환 후 React 의존성을 각각 검토한다.
- 실제 공개 배포 전에 보안 업데이트와 사용 경로 검토를 완료한다.

재확인 명령: npm audit. 전체 취약점이 해결되었다는 의미로 기본 CI 통과를 해석하지 않는다.
