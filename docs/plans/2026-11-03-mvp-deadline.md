## 변경 기준·현재 상태

2026-11-03 사용자 지시에 따라 R01–R08·F01–F12 **전체 20개**의 MVP 구현·고객/관리 UI·API 연결·필수 인수 기한을 **2026-12-31 Asia/Seoul**로 확정한다. P1/P2는 구현 순서이며 필수 범위를 줄이지 않는다. 개선·최적화는 2027-01-01 이후, 최종 기한은 2027-02-05로 유지한다. 2027-02-06 00:00부터 새 구현·커밋·병합을 중단하고 마지막 상태와 미완료·차단을 인계한다.

Frontend 일정 정본은 [React 이전·인수 계획](2026-10-31-react-migration.md)이며 이 문서는 새 기한의 세부 기준이다. Backend의 API/DB·검색 계약과 Recommendation의 데이터/모델 정본은 각 소유 저장소에서 관리한다. 여기서는 웹 소비·기능 인수·선행만 연결하며 다른 영역의 상세 계획을 복제하지 않는다.

- 기준 main `7c555ac`: Vite·React·TypeScript·Router·TanStack Query·Zustand의 실제 고객/관리 라우트 이전(FE02)은 완료했다. FE03/C04 전체 동등성·실제 조합 인수는 진행 중이다.
- 필수 기능 완료는 **3/20(R01·F01·F03)**이다. 부분 제공자·화면 증분·선택한 실제 통합 성공을 전체 기능 완료로 바꾸지 않는다. DB 전환·검색 기술 작업과 FE 하위 수정은 20개에 추가 합산하지 않는다.
- F02의 가격/도수·맛/향 리터럴 AND와 반복 URL은 연결됐다. 엔진·자동완성·검수 동의어/오타 등 전체 검색 인수는 남는다. 비ASCII의 제공자 정규화·400 입력 보존과 기존 적용/초안·페이지 소유를 유지한다.
- PostgreSQL/JPA의 제공 API는 순차 검증 중이다. 과거 MySQL/fixture 근거를 전체 PostgreSQL 전환·현재 세 서버 인수로 바꾸지 않는다.

## 12월 내 필수 인수와 1월 추가 검증

각 기능은 고객 경로와 필요한 관리자 관리 경로·실제 API를 연결하고 다음을 충족한 뒤 완료로 기록한다.

- 정상·로딩·빈 결과·오류와 명시 복구, 필요한 기본 키보드 조작/포커스·접근 이름·좁은 웹 화면을 확인한다. 기본 접근성은 1월로 이월하지 않는다.
- 비회원/본인/타 계정/관리자 권한·세션 회수와 비공개 데이터 격리를 검증한다. 권한 실패를 성공·빈 목록으로 숨기지 않는다.
- 최신 요청·현재 초안·중복 쓰기·실패 보존, null/[]/실제 0·삭제 이력·주문 당시 금액 등 해당 정합성을 확인한다. 계정 병합·알림 읽음·추천 제외/필수 조건도 각 계약을 검증한다.
- 실제 Backend/Recommendation/목표 DB의 주요 사용자 흐름을 기능별 기대/실제 결과와 연결한다. fixture 응답 처리·실제 통합·모델 사실/품질 근거는 분리하고 미완료·대체·제한을 표시한다. 후속 조회 실패와 이미 승인된 쓰기 결과도 구분한다.
- [TESTING](../TESTING.md)의 기존 `npm run check`와 필수 `frontend-ci`, 최신 head 완료 Codex 리뷰·미해결 지적 없음·main 검증을 유지한다. 문서 PR도 필수 CI를 생략하지 않는다.

1월에는 이 MVP 기준을 통과한 뒤 더 넓은 보조기술/브라우저·시각 조합, 추가 접근성/렌더링 개선, 모델·장애/동시성의 확장 검증과 실측 최적화를 진행한다. 필수 추천 학습·평가·장애 대체나 기능 정합성 검증을 선택 개선으로 분류해 늦추지 않는다. 시간 성능은 비교 가능한 실측 없이 주장하지 않는다.
